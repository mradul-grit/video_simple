# Product steering

- Product: StoryForge AI Studio, a story-aware talking-head-to-short-video editor.
- Primary customer: educators, trainers and professional explainers.
- Signature differentiator: timestamped, contextual, editable visual suggestions aligned to the speaker's story.
- Core promise: user tells the story; AI proposes an edit; user approves; application exports a polished vertical video.
- Original media is immutable. All edits live in a versioned edit manifest.
- Separate verbatim transcript/accessibility captions from concise editorial captions.
- Every caption must be grounded in transcript spans; every visual asset must retain license/creator/source metadata.
- User approval is required for cuts, editorial captions and visual placement. Automation intensity is configurable.
- Do not add scope simply because it is technically interesting. Protect MVP focus.
