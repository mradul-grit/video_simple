# Beta release checklist

- [ ] Product name, domain and trademark search reviewed.
- [ ] Terms of service and privacy policy reviewed by a qualified professional.
- [ ] Media retention, deletion and backup behavior tested and documented.
- [ ] All AI providers and data-transfer destinations disclosed.
- [ ] Cloud budget, quotas, alerts and shutdown plan reviewed.
- [ ] No hard-coded secrets; secret scanning and dependency scans pass.
- [ ] Auth, ownership, signed URLs and deletion tests pass.
- [ ] Asset licenses and attribution verified end-to-end.
- [ ] Test suite and golden media export pass.
- [ ] Android real-device tests pass; iOS verified on macOS/Xcode before claiming support.
- [ ] Low-end Android and slow-network behavior evaluated.
- [ ] Crash reporting and privacy-safe operational monitoring configured.
- [ ] Support process and user feedback channel ready.
- [ ] App store platform policies and user-generated media obligations reviewed.
- [ ] No public claims unsupported by evaluation data.
